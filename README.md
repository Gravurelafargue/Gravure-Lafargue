# SARL Gravure Lafargue

Site internet de la **SARL Gravure Lafargue** : restauration de sépultures, redorure, gravure et linogravure sur plaque, en Vendée.

- **Site** : [gravurelafargue.fr](https://gravurelafargue.fr)
- **Contact** : contact@gravurelafargue.fr

## Contenu

| Fichier | Rôle |
|---|---|
| `index.html` | Le site public : prestations, avant / après, linogravure, réalisations, notre méthode, demande de devis |
| `admin.html` | L'espace atelier (accès par mot de passe) : demandes de devis, statistiques, photos, textes et pages légales |

Les contenus modifiables (textes, photos, demandes de devis) sont enregistrés dans une base de données sécurisée, et non dans ce dépôt.
